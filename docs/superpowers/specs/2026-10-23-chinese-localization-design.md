# P(doom) 视频中文化设计

## 目标

以 `pdoom-video` 为视觉与技术基线创建独立副本 `pdoom-video-zh`。保留原曲、镜头、节奏、动画、颜色和渲染方式，只把成片中可见的英文歌词、界面文案、图表标签与注释改成简体中文。

## 边界

- 不修改 `/Users/charlotte/code/audio/pdoom-video`。
- 英文原唱与现有逐词时间戳保持不变；中文歌词按原词时段分配，以维持逐词卡拉 OK 动画。
- ChatGPT、Sydney、Gato、Loom 等专有名词可保留；AGI、GPU、RLHF、MLP、CDR、FOOM 等在画面中使用中文含义，必要时保留数学记号 `P(doom)`。
- 代码注释、开发文档和内部查询键不属于成片可见文案，不做全文翻译。
- 使用项目内置的简体中文字体，避免导出时依赖系统字体。

## 方案

1. 直接改写歌词 JSON：实现简单，但会破坏依赖英文歌词查找和词义分支的场景逻辑，不采用。
2. 为歌词模型增加“英文源词 + 中文显示词”双层数据：时间轴和场景判断继续使用英文，绘制使用中文；采用此方案，兼顾稳定性与逐词同步。
3. 只叠加中文字幕：成本最低，但保留大量英文画面文字，不能满足“其中英文改为中文”，不采用。

## 视觉决策

保持原片的黑、骨白、危险橙配色及版式。中文歌词使用内置 Noto Sans CJK SC，并沿用原场景的字号、动势与高亮时机；若中文长度改变，优先保持安全区与镜头意图，而不是机械复制英文字符宽度。

## 验收

- 原项目 Git 状态与 HEAD 不变。
- 46 行歌词均有中文显示文本，起止时间完整覆盖原英文演唱区间。
- 所有场景仍能通过 TypeScript 检查、生产构建和浏览器逐场景渲染。
- 抽样帧中中文字体正常、无缺字方框、无运行时错误，主要文案位于安全区。
